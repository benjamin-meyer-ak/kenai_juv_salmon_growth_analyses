4.1 Overview

This chapter documents the exploration and summary of diet composition data collected via gastric lavage from juvenile Chinook and Coho salmon in the Kenai River watershed during the 2015 and 2016 field seasons. The goals of this chapter are:

  1. Describe the diet dataset: sample sizes, taxa richness, and data quality
  2. Convert prey dry mass estimates to wet mass using wet/dry ratios from the literature
  3. Calculate prey category proportions (by wet mass) for each fish and at grouped scales
  4. Produce summary figures and tables disaggregated by species, age, river, and season

4.2 Data Import

We import diet contents data from the two primary field data workbooks. Columns are selected and renamed to a consistent lowercase schema. Both years are combined into a single data frame before any transformations.

The two source files are:

  • other/inputs/diet_size_other/2015 EPSCoR SCTC.xlsx (sheet: “2015 Diet Contents Data”)
  • other/inputs/diet_size_other/2016_EPSCoR_Aquatic_Ecology_Database.xlsx (sheet: “2016 Diet Contents Data”)

Dry mass values in these sheets were estimated from measured prey item lengths using length-weight regressions (W = aL^b), where parameters were drawn from the literature. These calculations were performed within the Excel workbooks using formula-based pipelines. The resulting Total_Prey_Dry_Mass_mg column is our starting point.

4.4 Dry Mass to Wet Mass Conversion, and Bioenergetics Prey Category Assignment

To express prey item mass in wet weight (the required unit for Fish Bioenergetics 4.0 inputs), we apply wet/dry mass ratios from McCarthy et al. 2009 and additional literature sources. These ratios are stored in other/outputs/diet/mass_conversion/prey_types_manual_edit.xlsx.

The general approach:

  1. Each unique prey taxon/lifestage in the dataset was manually assigned to one of a set of broader prey type categories (this mapping was done once and is stored in the prey_types sheet of the conversion workbook)
  2. Each prey type category has an associated wet/dry ratio, energy density, and bioenergetics diet-slot category from the literature (stored in the data_validation sheet, columns wet_dry_ratio, energy_density_jg, and PreyCategory_ED)
  3. We join these values to the diet data and compute wet mass as: wm_mg = dm_mg / wet_dry_ratio

Note that the raw PreyCategory field recorded in the source workbooks (retained here as preycat_field) is a field-level classification (origin: terrestrial/aquatic/unknown) and is not the same as the five-category bioenergetics diet-slot scheme used for FB4 inputs (Diet1-5: FishEggs, InvertAquatic_AqOrigin, InvertTerrestrial, InvertTerrestrial_AqOrigin, SalmonEggs). The latter comes from PreyCategory_ED in the conversion workbook, keyed to each prey taxon’s assigned prey_type. All downstream summaries and figures in this chapter use PreyCategory_ED (as preycat), not preycat_field.

Code 
dm_convert_prey_types <- read_excel(
  "other/outputs/diet/mass_conversion/prey_types_manual_edit.xlsx",
  sheet = "prey_types", skip = 1
) |>
  select(-notes)

dm_convert_vals <- read_excel(
  "other/outputs/diet/mass_conversion/prey_types_manual_edit.xlsx",
  sheet = "data_validation"
) |>
  filter(!is.na(prey_type))

dm_convert_vals <- left_join(dm_convert_prey_types, dm_convert_vals, by = "prey_type") |>
  filter(!is.na(wet_dry_ratio)) |>
  select(-notes) |>
  rename(prey = unique_diet_prey)

diet <- left_join(diet, dm_convert_vals, by = "prey") |>
  filter(!is.na(wet_dry_ratio)) |>
  mutate(
    wm_mg   = dm_mg / wet_dry_ratio,
    preycat = factor(PreyCategory_ED, levels = c(
      "SalmonEggs", "FishEggs",
      "InvertAquatic_AqOrigin", "InvertTerrestrial_AqOrigin",
      "InvertTerrestrial"
    ))
  )

4.6 Diet Proportions by Wet Mass

We calculate the proportion of total wet mass contributed by each prey category, at multiple levels of grouping. Results at the fish level (per-fish proportions) are used for summaries; grouped proportions (pooled across fish within a group) are used as bioenergetics model inputs (Chapter 4).

A fish that did not eat a given prey category has no row for that category, not an explicit zero. If left that way, a later group-level average of prop_wm (e.g., mean proportion of salmon eggs in a river/season/species/age group) would be computed only over the fish that did eat that category, rather than over all fish in the group. Category means computed this way do not share a common denominator, and can sum to well over 100% when stacked. We fix this by completing each fish’s record with explicit zero-mass rows for every prey category it did not eat, so every fish contributes to every category’s denominator downstream.

Code 
# Per-fish wet mass by prey bioenergetics category
diet_per_fish <- diet |>
  group_by(sample.id, spp, age, year, river, season, preycat) |>
  summarise(wm_mg = sum(wm_mg, na.rm = TRUE), .groups = "drop") |>
  # Explicit zeros for uneaten categories; see note above
  complete(nesting(sample.id, spp, age, year, river, season), preycat, fill = list(wm_mg = 0))

# Per-fish total wet mass (denominator)
fish_totals <- diet_per_fish |>
  group_by(sample.id) |>
  summarise(total_wm_mg = sum(wm_mg), .groups = "drop")

# Per-fish proportions
diet_props <- left_join(diet_per_fish, fish_totals, by = "sample.id") |>
  mutate(prop_wm = wm_mg / total_wm_mg)

4.7.1 Prey Composition by River, Season, and Age

The primary visualization is a stacked bar chart of mean wet-mass proportions, faceted by river (column) and age class (row), with season on the x-axis. # Shared summary + plotting helpers for the three diet composition figures below
summarise_diet <- function(data) {
  data |>
    group_by(river, season, age, preycat) |>
    summarise(
      mean_prop = mean(prop_wm, na.rm = TRUE),
      n_fish    = n_distinct(sample.id),
      .groups   = "drop"
    ) |>
    mutate(
      season = factor(season, levels = c(
        "Early Summer", "Mid-Summer", "Late Summer", "Fall")),
      age_label = paste0("Age ", age)
    )
}

plot_diet_bars <- function(data) {
  ggplot(data, aes(x = season, y = mean_prop, fill = preycat)) +
    geom_col(position = "stack") +
    geom_text(
      aes(label = n_fish, group = preycat),
      stat = "summary", fun = sum,
      position = position_stack(vjust = 1.05),
      size = 2.5, check_overlap = TRUE
    ) +
    facet_grid(age_label ~ river) +
    scale_y_continuous(labels = scales::percent_format()) +
    scale_fill_manual(values = preycat_colors, labels = preycat_labels) +
    labs(
      x = "Season",
      y = "Mean proportion of diet (wet mass)",
      fill = "Prey category"
    ) +
    theme_bw() +
    theme(axis.text.x = element_text(angle = 35, hjust = 1))
}

4.10 Notes and Data Quality

  • Prey items that could not be assigned a wet/dry ratio (i.e., did not match any entry in the conversion table) are excluded from all wet-mass calculations. This includes placeholder/non-prey entries recorded as Bait, Bait EGGS, Empty/EMPTY, and 0 (empty-stomach or bait-contamination codes), which have no conversion-table match and are dropped naturally at that step.
  • The preycat field used throughout this chapter is the bioenergetics diet-slot classification (PreyCategory_ED) from the conversion workbook, not the raw field-recorded PreyCategory column (kept as preycat_field); the two classification schemes disagree for some taxa (e.g., oligochaetes), and only PreyCategory_ED is used for FB4 diet-slot inputs.
  • Fish without an assigned age (Age_manual2 = NA) are excluded from age-disaggregated summaries.
  • Per-fish diet proportions are completed with explicit zeros for uneaten prey categories before group-level averaging (see the Diet Proportions section); without this step, stacked group means do not sum to 100%.
  • Age-2 Coho and age-1 Chinook are excluded from the analysis following Meyer et al. 2023 (these cohorts are sparse and likely transitioning out of freshwater rearing).

## Diet Proportions by Wet Mass

We calculate the proportion of total wet mass contributed by each prey category, at multiple levels of grouping. Results at the fish level (per-fish proportions) are used for summaries; grouped proportions (pooled across fish within a group) are used as bioenergetics model inputs (Chapter 4).

A fish that did not eat a given prey category has no row for that category, not an explicit zero. If left that way, a later group-level average of `prop_wm` (e.g., mean proportion of salmon eggs in a river/season/species/age group) would be computed only over the fish that did eat that category, rather than over all fish in the group. Category means computed this way do not share a common denominator, and can sum to well over 100% when stacked. We fix this by completing each fish's record with explicit zero-mass rows for every prey category it did not eat, so every fish contributes to every category's denominator downstream.

```{r diet-proportions}
# Per-fish wet mass by prey bioenergetics category
diet_per_fish <- diet |>
  group_by(sample.id, spp, age, year, river, season, preycat) |>
  summarise(wm_mg = sum(wm_mg, na.rm = TRUE), .groups = "drop") |>
  # Explicit zeros for uneaten categories; see note above
  complete(nesting(sample.id, spp, age, year, river, season), preycat, fill = list(wm_mg = 0))

# Per-fish total wet mass (denominator)
fish_totals <- diet_per_fish |>
  group_by(sample.id) |>
  summarise(total_wm_mg = sum(wm_mg), .groups = "drop")

# Per-fish proportions
diet_props <- left_join(diet_per_fish, fish_totals, by = "sample.id") |>
  mutate(prop_wm = wm_mg / total_wm_mg)
```

## Notes and Data Quality

- Prey items that could not be assigned a wet/dry ratio (i.e., did not match any entry in the conversion table) are excluded from all wet-mass calculations. This includes placeholder/non-prey entries recorded as `Bait`, `Bait EGGS`, `Empty`/`EMPTY`, and `0` (empty-stomach or bait-contamination codes), which have no conversion-table match and are dropped naturally at that step.
- The `preycat` field used throughout this chapter is the bioenergetics diet-slot classification (`PreyCategory_ED`) from the conversion workbook, not the raw field-recorded `PreyCategory` column (kept as `preycat_field`); the two classification schemes disagree for some taxa (e.g., oligochaetes), and only `PreyCategory_ED` is used for FB4 diet-slot inputs.
- Fish without an assigned age (Age_manual2 = NA) are excluded from age-disaggregated summaries.
- Per-fish diet proportions are completed with explicit zeros for uneaten prey categories before group-level averaging (see the Diet Proportions section); without this step, stacked group means do not sum to 100%.
- Age-2 Coho and age-1 Chinook are excluded from the analysis following Meyer et al. 2023 (these cohorts are sparse and likely transitioning out of freshwater rearing).
